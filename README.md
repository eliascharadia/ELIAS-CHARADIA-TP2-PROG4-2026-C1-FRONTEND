## Descripción del Proyecto

RobbieSocial es una aplicación web desarrollada como una red social donde los usuarios pueden registrarse, iniciar sesión, administrar su perfil y compartir publicaciones. El proyecto se desarrolla utilizando Angular para el frontend.
